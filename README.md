# Stock Price Prediction using Machine Learning

## Overview
The project predicts stock prices using the historical market data & machine learning techniques. 
This model is trained on previous stock price trends and it attempts to forecast the future prices.

## Features
- Visualization of actual vs predicted prices
- Historical stock data analysis
- Stock price prediction
- Machine Learning model training
- Data preprocessing

## Technologies Used
- Python
    - Pandas
    - NumPy
    - Scikit-learn
    - Matplotlib
    - yFinance

## Project Workflow
1. Collect the stock data
2. Clean & preprocess data
3. Train the ML model
4. Predict the stock prices
5. Evaluates the performance
6. Visualizes the results

## Results
The model is evaluated using the RMSE and MAE metrics.
